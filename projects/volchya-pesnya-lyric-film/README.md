## Reproduce the preview

Use Node 24+, FFmpeg/ffprobe and the locked native Canvas dependency. Restore the exact original MP4 as `public/source.mp4` and verify [its SHA-256](source/recording.json). Then:

```sh
npm ci
npm run check
npm run identity
npm run preview
```
