# Publishing kit

- YouTube: use `YouTube-title.txt`, `YouTube-description.txt`, the 1920×1080 video, and `Polovinka-YouTube-Thumbnail-1920x1080.jpg`.
- TikTok: use `TikTok-description.txt`, the 1080×1920 video, and `Polovinka-TikTok-Profile-1200x1600.jpg`. No separate TikTok title is supplied.
- Optional captions: Russian, English and bilingual SRT/VTT files in `captions/`.

The films contain Russian and English only. All publishing copy is prepared locally; no platform upload or rights-holder correspondence has been performed.
