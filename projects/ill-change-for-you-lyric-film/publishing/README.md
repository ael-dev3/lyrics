# Posting assets and cover provenance

The upload copy is in the four platform text files in this directory. [Official release information](https://thelabel.co.nz/mitski-presents-ill-change-for-you-single-video/) supports the music/video credits. The original recording and film are identified in the [source manifest](../source/media-manifest.json). Public descriptions disclose an independent AI-assisted lyric edit and link to the original video.

Both covers are generated by [the cover script](../scripts/make-publishing-covers.py) from **the same locked source frame at 00:45.000**, with its SHA-256 checked before export. The 1920×1080 YouTube thumbnail uses a top-anchored source crop so Mitski’s face remains in view. The 1200×1600 TikTok cover is a separate portrait composition centered on Mitski. Neither cover uses replacement image-generation artwork. Their type and soft plum reading fields echo the actual video frame; text stays below the face in the portrait edition.

Native and small-size local proof images are in [cover review](../evidence/cover-review/). The 320×180 YouTube view and 150×200 TikTok view keep the complete title, artist and source subject legible. A 5% edge crop simulation preserves those elements in both. These are local checks, not claims about a platform upload preview. [Cover hashes, size and orientation](../evidence/cover-assets.json) are recorded separately; source-image rights are excluded from the repository contribution license.

After both full videos have passed technical and picture/word review, run [the kit assembler](../scripts/assemble-posting-kit.py) with `--youtube`, `--tiktok` and a **new** `--dest` staging path. It verifies 4:3 and 9:16 H.264/AAC video structure and duration, copies the exact film and cover bytes, generates optional 25-line English SRT/VTT from the approved timeline, and writes a SHA-256 inventory. It does not render a film or replace the independent final-file QA. Verify hashes again after copying the kit to the requested Desktop folder; keep that posting folder intact for manual upload.
