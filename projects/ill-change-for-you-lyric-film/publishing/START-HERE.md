# Mitski — I’ll Change for You | posting kit

Both videos contain the complete song and on-screen English word highlighting. This kit is for manual posting; no upload has been performed.

## YouTube

Upload `YouTube/Mitski-Ill-Change-for-You-YouTube-4x3.mp4` as the full 4:3 film. Copy `YouTube/title.txt` and `YouTube/description.txt` into the upload form. Choose `YouTube/thumbnail.jpg` as the custom 1920×1080 thumbnail.

## TikTok

Upload `TikTok/Mitski-Ill-Change-for-You-TikTok-9x16.mp4` as the full 1080×1920 portrait film. Copy `TikTok/description.txt`; `TikTok/title.txt` supplies a short optional title. Choose `TikTok/profile-cover.jpg` for the portrait 1200×1600 profile cover.

## Optional captions and file check

`Captions/english.srt` and `Captions/english.vtt` contain selectable English line captions aligned to the approved timeline. The videos already show the lyric words. `Delivery-Manifest.json` records file sizes and SHA-256 identities; `SHA256SUMS.txt` lets you check every posting file before upload with `shasum -a 256 -c SHA256SUMS.txt` from this folder.
