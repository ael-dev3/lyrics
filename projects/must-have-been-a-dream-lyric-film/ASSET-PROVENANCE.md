# Source and asset provenance

The picture and soundtrack are the original [Computer Kill — Must Have Been A Dream official video](https://www.youtube.com/watch?v=AK6duyCPU50). The preview draws the decoded video into both layouts; there is no replacement background, character or soundtrack. Credits in the official video description identify Computer Kill, A POSTMORTĒ PRODUCTION, director/editor Rob Roy Taylor, producer/editor Tommy Melendez, cinematography by Joseph Puccio, and VFX by Isaac Barnes. Those credits describe the source video, not this lyric treatment.

Match the locked hash before building the preview; a later server response may package different bytes. Do not commit the original MP4. The preview server serves local media with byte ranges, but Git contains the scene code and small source-derived measurements only.

The source file includes 204-pixel encoded black bands above and below its active image. The current lyric composition crops to the active 1920×672 picture and fills both output frames without geometric stretch. Contiguous shot intervals choose the landscape and portrait centers; source title and credit passages carry explicit review flags. At 43.35–44.12 s, the artist name is keyed from the source's red pixels and placed over a stage frame from the same video in landscape; portrait redraws its words in a narrow arrangement. The following moving artist card uses full active source width over a blurred extension in landscape. The later song-title flash extracts the current frame's colored title in landscape; portrait sets the same wording with locally drawn Archivo Black lettering colored from the source frame. In daylight end credits, incomplete red credit fragments in portrait are repaired locally from adjacent pixels in each moving source frame; landscape leaves the original credits intact. The active sung word carries measured warmth and transient color; existing lamps, glass, pavement and stage beams host source-measured response. A color mask brightens selected original red or blue pixels. There is no freestanding graph. The sprite deliberately reuses earlier source motion during the source blackout; it is not contemporaneous footage from that interval. The complete preview passed owner listening and both-layout review; both encoded masters passed the [independent final-file checks](evidence/final-verification.json).
