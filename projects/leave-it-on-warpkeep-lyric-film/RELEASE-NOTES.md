# Leave It On — Warpkeep lyric film v1.0.0

A complete English lyric film for the original **Leave It On** recording, set around Warplet's Watch. The castle, rooftop guardian and landscape come from [Warpkeep PR #375](https://github.com/ael-dev3/Warpkeep/pull/375). Lyrics glow as a magical forecourt inscription while measured music drives the stone visualizer, guardian rune field and cyan/violet gate light. The 3D WARPKEEP mountain sign points to the [Warpkeep Farcaster channel](https://farcaster.xyz/~/channel/warpkeep).

## Source and publishing assets

The `Leave-It-On-Warpkeep-Source-<commit>.zip` archive contains the exact merged project source, unchanged supplied audio master, packet-preserving preview remux, frozen Warpkeep assets, fonts, lyric candidate map, reproducible render and verification scripts, publishing kit, and SHA-256 inventories. The local **Leave It On - Warpkeep** Desktop folder organizes the two posting files, YouTube title/description/tags/thumbnail, TikTok title/caption/profile and vertical covers, source ZIP and verification records. Publishing copy is prepared for those platforms; this release does not represent a post to either platform.

The [project record](https://github.com/ael-dev3/lyrics/tree/main/projects/leave-it-on-warpkeep-lyric-film) documents the frozen `preview-v2-pr375` source identity, Warpkeep asset hashes, source-clocked scene and audio analysis. The release media and source archive have separate verification inventories; the archive is the reproducible source for this edition rather than an assumption that a later branch state is identical.

## Review scope and evidence limit

The owner reviewed the complete browser preview and explicitly authorized both final formats, Desktop delivery and this repository release. Final-file verification checks complete decoding, frame count and cadence, picture geometry/color metadata, AAC delivery audio, original Opus packet identity in the archival masters, representative decoded frames and copied/uploaded asset hashes. The 63 lyric cues and 343 word events are the frozen acoustic candidate map. An independent every-cue listening and phonetic audit was not recorded; the ordinary granular synchronization gate remains closed. This edition follows the documented, scoped owner-approved-preview production path and does not present model alignment as perfect vocal proof.

Visual production and lyric workflow: **Ael**, with AI assistance. Game world, models and emblem retain their [Warpkeep provenance](https://github.com/ael-dev3/Warpkeep/pull/375).
