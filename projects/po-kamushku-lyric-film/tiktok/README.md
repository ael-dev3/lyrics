# По камушку — TikTok cover

The profile cover is **1200 × 1600 pixels, 3:4 portrait**. It preserves the complete original stone circle and person, with the complete song title and artist stacked beneath the square photograph. Additional poster space uses empty soil from that same artwork. Alegreya, ivory and clay match the approved film; no replacement artwork is generated.

Generate the selected JPEG and local size/crop proofs with `node scripts/make-covers.ts --dest /absolute/project/staging/folder`. Review `analysis/covers/tiktok-150x200.png`, `tiktok-300x400.png` and `tiktok-center-crop-5percent.png`. Set the cover evidence to passed only after inspecting the actual generated files and their hashes.

The upload filename is `Po-Kamushku-Settlers-TikTok-Cover-Profile-1200x1600.jpg`. Use it with the 1080 × 1920 full-song film and `publishing/TikTok-Description.txt`. The 150 × 200 and 5% crop images are local simulations; no TikTok upload-interface test or platform posting is implied.

Source recording and artwork: [Settlers — По камушку](https://www.youtube.com/watch?v=oysjDP9Vqdg), provided through ONErpm, ℗ Snegiri-music. The original source credits do not separately identify an artwork creator. Preserve the repository's third-party material exclusions.
