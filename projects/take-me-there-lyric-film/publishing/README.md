# TAKE ME THERE — posting assets

These are the title, description and cover choices for the YouTube and TikTok posting kit. The finished films and the original source MP4 are kept outside Git. No video-platform upload is represented here.

The covers use frames decoded from the exact [excape. — TAKE ME THERE source video](https://www.youtube.com/watch?v=CPznmfSbAiE) used by the film (MP4 SHA-256 `954ce98a308937e81a167ab740381cd46195abbad3279f3bc57319fa48bbd73c`). Space Grotesk lettering and a light shade in the existing sky improve cover-size reading. No replacement scenery or character image was generated.
