# Workflow study for the acoustic lunar preview

Applied the repository workflow in general: original audio identity, bounded alignment, independent recognition, complete semantic correspondence, equal bilingual layout, deterministic display states, playable review before production, and verification before GitHub merge.

| Study | Applied principle |
| --- | --- |
| [First pass](../../../docs/first-pass-song-workflow.md) | Verify source identity, preserve full duration, treat recognition as a candidate |
| [Preview before render](../../../docs/preview-before-render.md) | Deliver both playable formats and stop before full capture until current-song approval |
| [Cross-language gate](../../../docs/cross-language-sync-gate.md) | Keep pending actual-audio evidence explicit and block stale/incomplete review |
| [Bilingual correspondence](../../../docs/bilingual-lyric-workflow.md) | Complete grammatical meanings and separate links for reordered words |
| [Cinematic lyric workflow](../../../docs/cinematic-lyric-workflow.md) | Stable color-only focus and equal language prominence |
| [Measured choreography study](../../../docs/studies/moyka-moon-2026/README.md) | Separate sung events, line visibility, structural transitions and decorative movement |
| [Production lessons](../../kazhdyy-lyric-film/PRODUCTION-LESSONS.md) | Give each effect a purpose; keep artistic strength separate from measurement and lyric timing |
| [Restrained response](../../tvoi-glaza-lyric-film/PRODUCTION-LESSONS.md) | Choose compact measured movement when the arrangement benefits from it |
| [TypeScript workflow](../../../docs/typescript-first-workflow.md) | Typed orchestration; Python only as a pretrained-model bridge |

Historical palettes, numeric emphasis windows and scene templates were not adopted as defaults. The new lunar artwork, centered composition, cold colors and radial response are decisions for this recording. This is a methods record, not a claim that another song inspired the visual edition.
